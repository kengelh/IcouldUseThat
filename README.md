# ICouldUseThat

A RimWorld mod that automates the tedious task of unforbidding and marking useful items for hauling.

## Features

- **Automated Unforbidding**: No more manual clicking on every piece of loot.
- **Smart Hauling**: Automatically marks items for hauling to your stockpiles.
- **Urgent Hauling Support**: Can use "Haul Urgently" if the Allow Tool mod is installed.
- **Customizable Filters**:
  - Filter by category (Weapons, Apparel, Food, Medicine, etc.).
  - Set minimum quality thresholds.
  - Set minimum hit point thresholds.
  - Toggle tainted apparel hauling.
- **Performance Friendly**: Uses efficient patching and queued processing to ensure no impact on TPS.

## Installation

1. Download the latest release.
2. Extract into your RimWorld `Mods` folder.
3. Enable "Harmony" and "I Could Use That" in the mod menu.

## Requirements
